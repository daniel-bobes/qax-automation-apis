# Quick Task
___
- 📁 **Carpeta:** `Stage_1/Quick_Task/`
- 🎯 **Objetivo:** Poner en práctica conceptos básicos de programación y utilización de Postman para las pruebas de APIs (API Testing).
## Ejercicio 1 - Java ☕
___
- 📁 **Carpeta:** `Stage_1/Quick_Task/QuickTask1`
- 🎯 **Objetivo:** Poner en práctica la inicialización y uso de variables, tipos de datos y funciones básicas.

### Instrucciones:
1. Crea un archivo llamado MiFicha.java.
2. Dentro, guarda tu información en variables:
   - Tu nombre (`String`)
   - Tu edad (`int`)
   - Si estás estudiando automatización en APIs (`boolean`)
   - Tu lista de hobbies (`String[]` o mejor `ArrayList<String>`)
3. Muestra la información en pantalla usando `System.out.println()`.
4. Usa `.getClass()` o .`getSimpleName()` para imprimir el tipo de cada variable
5. Muestra cuántos hobbies hay en total con `.size()`.
6. Cambia el valor de la edad sumándole 1 (como si hubieras cumplido años) y vuelve a mostrarlo en pantalla.

## Ejercicio 2 - Postman 📨
___
- 📁 **Carpeta:** `Stage_1/Quick_Task/QuickTask2`
- 🎯 **Objetivo:** Poner en práctica la ejecución de requests y la importación de colecciones en Postman.

### Instrucciones:
1. Descarga la colección [Stage 1 Warm Up - Api Testing - QAXPERT.json](https://github.com/daniel-bobes/qax-automation-apis/blob/5bb1042e20c09cfca38f4a464a2b51cd80bd1cc9/Stage_1/Quick_Task/QuickTask2/Stage%201%20Warm%20Up%20-%20Api%20Testing%20-%20QAXPERT.json) desde GitHub.
2. Abre Postman en tu máquina o en el cliente web.
2. Haz clic en Import (arriba a la izquierda).
3. Selecciona Upload Files y carga la colección descargada en el paso 1.
4. Verifica que la colección Api Testing - QAXPERT aparece en tu panel izquierdo.
5. Ejecuta al menos una petición de la colección para confirmar que la importación fue exitosa.
