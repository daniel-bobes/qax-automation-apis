# Portafolio de Automatización de APIs con Rest Assured y Java - Daniel Bobes

¡Hola! Soy **Daniel**, Analista QA enfocado en construir soluciones de automatización robustas y escalables para APIs.

Este repositorio es el núcleo de mi formación en la mentoría **QA Pro Level de QAX**.

Mi objetivo es demostrar mis habilidades para crear, ejecutar y mantener tests robustos y confiables, garantizando la mejor calidad.
___
### 🚀 Tecnologías que utilizo 
- **Lenguaje:** Java 11+ ☕
- **Frameworks de Automatización:** Rest Assured, Cucumber (BDD) 🥒
- **Gestión:** Maven, JUnit, TestNG 🏗️
- **Otras herramientas:** Git, Postman 🚀
___
### 📚 Roadmap de proyectos

#### 🟢 Stage 1: Fundamentos de API Testing con Rest Assured
- **QuickTask**: Configuración de entorno y validación inicial de APIs con Postman.
- **Challenge:** Automatización de un CRUD completo para la API de gestión de usuarios. 📁[Ver Carpeta](./Stage_1/Challenge/) 
- **Mission:** Creación de un framework base para pruebas de API con reportes personalizados. 📁[Ver Carpeta](./Stage_1/Mission) 

#### 🔵 Stage 2: Frameworks de Automatización Avanzados
- **Estado:** En desarrollo.
- **Objetivo:** Implementación de BDD con Cucumber, POJO y flujos avanzados con autenticación.
___
### 🧪 Ejecución de Pruebas
Para ejecutar cualquier proyecto de este repositorio:
1. Clonar el repositorio.
    ```bash
    git clone https://github.com/daniel-bobes/qax-automation-apis.git
    ```
2. Entrar al directorio del proyecto que queremos ejecutar.
    ```bash
    cd [Nombre_de_la_carpeta]
    ```
3. Ejecutar los test.
    ```bash 
    mvn clean test
    ```
4. Ver el reporte. Los resultados se generan en `target/surefire-reports` (Stage 1) o en `target/cucumber-reports` (Stage 2).
